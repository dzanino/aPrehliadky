# aPrehliadky — offline forensic 3D documentation for iPhone (LiDAR photogrammetry)

**aPrehliadky** is a photogrammetric 3D scanner for bodies, objects and crime scenes, built for
forensic pathologists, examining physicians, crime-scene technicians and expert witnesses.
Capture with iPhone LiDAR, reconstruct entirely on the device, measure on the model with a stated
uncertainty, pin findings to the surface, and export a PDF report with a **class A–D 3D
documentation certificate** and an **.f3d package** with SHA-256 hashes. No cloud, no account,
no upload.

- Product page (SK / EN): **https://forensika.eu/aprehliadky/** · https://forensika.eu/en/aprehliadky/
- App Store (free, iOS 18+): https://apps.apple.com/app/id6808879666
- Mac companion **Fotograme3ka 3D** (recompute at higher detail): https://forensika.eu/fotograme3ka/
- Guides, calibration target T3 (fiducial centres 247.00 mm), certification methodology: this site → https://dzanino.github.io/aPrehliadky/
- Part of the **Forensika** family of offline forensic-medicine apps: https://forensika.eu/
